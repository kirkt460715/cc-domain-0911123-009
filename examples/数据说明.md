# 车间同时电量与生产任务

series 是同一网格上每格的 kWh，main 为总表，其余是子表；允许总分表存在正残差。grid_seconds 为每格秒数。tasks 中功率为 kW，duration 和 original_start、earliest、latest_end、available 均采用格索引，结束边界不包含该格；after 是前置任务标识。总电量应由功率乘持续时间得出。capacity_kw 为厂区需量上限，tree 是总分表包含关系。

`examples.context` 把每格电量转换为累计读数导入分能，并核对真实重建结果；它不会运行计划搜索或改变原始读数。

需要同时性与移峰分析时，用同一份数据登记任务后调用计划入口：

```python
from examples.context import load
from energyflow.service import EnergyService

data = load()
width = data["grid_seconds"]
end = len(data["series"]["main"]) * width
with EnergyService() as app:
    # 导入读数、费率的步骤与 examples.context 相同。
    for task in data["tasks"]:
        app.planning_tasks.put(
            task["id"],
            task["meter"],
            0,
            end,
            width,
            task["original_start"],
            task["duration"],
            task["power_kw"],
            earliest=task["earliest"],
            latest_end=task["latest_end"],
            available=task["available"],
            after=task["after"],
        )
    plan = app.planning.plan(
        "main", data["tree"], 0, end, width, data["capacity_kw"]
    )
```

`plan["status"]` 为 `optimal` 时，`curves` 逐格给出各表前后功率，`tasks` 给出每个任务的基线格和新安排，`demand.key_windows` 给出关键需量窗口，`cost` 给出费用差，`checks` 可逐格核对能量守恒、容量与依赖。计划只做模拟，不改变读数或封账记录；同一输入重复计算得到相同 `result_digest`。
